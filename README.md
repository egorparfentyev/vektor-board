# Вектор — интерактивная доска

Математика и физика: графики функций, геометрические фигуры, динамические опыты, единичная окружность, ручка/перо/мел, частичный ластик, тетради и экспорт PDF/PNG/JPEG.

Публичный сайт: https://vektor-board-egor.web.app

## Firebase

Проект: `vektor-board-egor`. Firebase Hosting + Authentication (email/пароль) + Firestore. Исходники не содержат аккаунтов, пользовательских досок, паролей, административных ключей и локальной базы старого приложения.

У каждого пользователя свой аккаунт. Создатель доски — преподаватель на этой доске; вошедший по приглашению — ученик. Правила Firestore разрешают изменять только свои элементы. Карточки целей и ДЗ редактирует создатель доски. Ссылка-приглашение работает после входа или регистрации, её нельзя перечислить через запрос коллекции. Передавайте ссылку участникам занятия.

## Запуск

Требуется Node.js 22.13+ и Firebase CLI 15.34+.

```sh
npm ci
npm install -g firebase-tools
firebase login
node scripts/configure.mjs vektor-board-egor
npm run dev
```

`configure.mjs` получает публичную конфигурацию веб-приложения через авторизованный Firebase CLI и записывает `.env.local`. Альтернатива: заполнить поля по `.env.example` данными Web App из Firebase Console. Firebase API key браузерного приложения не является административным ключом; доступ контролируют Authentication и Security Rules. Приватные ключи service account не нужны для клиентской сборки и не должны попадать в Git.

## Публикация

```sh
npm run build
firebase deploy --only hosting,firestore,auth --project vektor-board-egor
```

База `(default)` размещена в `europe-west3`. На новом проекте сначала создайте Web App и базу Firestore; правила по умолчанию должны запрещать доступ. Конфигурация включения Email/Password находится в `firebase.json`.

## PDF позже

По решению владельца первая публикация использует бесплатный тариф Spark, без Cloud Storage. Обычные тетради и экспорт работают; загрузка PDF отключена явным флагом. Код загрузки и правила Storage подготовлены.

Для подключения PDF владелец должен самостоятельно подключить Blaze и создать default Storage bucket. Затем:

1. Проверьте `VITE_FIREBASE_STORAGE_BUCKET` в `.env.local`.
2. Установите `VITE_PDF_UPLOADS=true`.
3. Настройте CORS bucket для домена сайта (скачивание через авторизованный Firebase SDK getBytes), примените `storage.rules`. Правила требуют членство в доске и собственную папку пользователя, ограничивают PDF до 20 МБ. При первом использовании Firestore в Storage Rules Firebase может запросить разрешение сервисному агенту.
4. Пересоберите и опубликуйте: `npm run build && firebase deploy --only hosting,storage`.

Платный тариф и платёжные аккаунты автоматически не подключаются. Официальные требования: https://firebase.google.com/docs/storage/web/start

## Данные прежней локальной версии

Старое приложение и `.wrangler` остаются в соседней папке `vektor`. Они не загружаются в репозиторий и автоматически не переносятся в Firebase. При первом входе создаётся новая пустая доска. Пользовательский email служит логином; пароли и их восстановление обрабатывает Firebase Authentication.
